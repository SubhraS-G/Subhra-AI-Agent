# MEMORY SYSTEM

## Permanent Memory

Long-term information that is stable and useful across projects.

Examples:
- Brand identity
- General preferences
- Long-term goals
- Established rules

## Project Memory

Information specific to a project.

Examples:
- Project purpose
- Repository
- Technology
- Current state
- Important files
- Decisions

## Workflow Memory

How recurring tasks are performed.

Examples:
- Thumbnail workflow
- YouTube workflow
- GitHub workflow
- Development workflow

## Temporary Memory

Short-lived task context.

Examples:
- Current video
- Current thumbnail
- Current bug
- Current campaign

## Learning Rules

Do not turn a single correction into a permanent rule.

Use confidence:

- Unknown
- Low
- Medium
- High
- Established

Example:

```yaml
preference:
  rule: "Use minimal thumbnail text"
  confidence: high
  evidence_count: 14
```
