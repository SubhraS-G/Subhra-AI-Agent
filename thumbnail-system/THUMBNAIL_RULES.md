# THUMBNAIL RULES

## Objective

Create professional creator thumbnails that are visually strong, readable, realistic, and consistent with the selected channel.

## Priorities

1. Clear focal point
2. Strong visual hierarchy
3. Natural creator appearance
4. Relevant game elements
5. Mobile readability
6. Appropriate contrast
7. Brand consistency
8. Minimal unnecessary elements

## Avoid

- Generic AI faces
- Plastic skin
- Distorted hands
- Warped objects
- Excessive glow
- Excessive particles
- Long text
- Unrelated objects
- Fake UI
- Overly busy compositions

## Text

Prefer short phrases. Do not duplicate the full video title on the thumbnail.

## Face

Use the real face-reference library when the creator is included.

## Output

Default YouTube thumbnail target:
- Aspect ratio: 16:9
- Common working resolution: 1280×720 or higher
