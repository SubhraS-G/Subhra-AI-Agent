# THUMBNAIL COMPOSITION

## Default Visual Hierarchy

1. Main subject
2. Main event
3. Supporting element
4. Short text
5. Branding

## Concept Process

Generate 3–5 concepts before committing when the task benefits from exploration.

Potential patterns:
- Creator face + main game element
- Large game element + creator reaction
- Cinematic gameplay scene + creator
- Before/after
- Challenge/result
- Character transformation

Do not treat these as fixed templates. Adapt composition to the actual video.

## Small-Scale Test

A thumbnail should remain understandable when reduced significantly.

If the focal point disappears or the text becomes unreadable, simplify.
