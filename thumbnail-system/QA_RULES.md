# THUMBNAIL QA RULES

## Technical

- Correct aspect ratio
- Correct resolution
- Valid file
- No accidental cropping
- No corrupted assets

## Face

- Recognizable identity
- Appropriate expression
- Natural skin
- No facial artifacts

## Objects

- Correct game assets
- No warped objects
- No duplicated elements
- No malformed hands/fingers

## Composition

- Clear focal point
- Strong separation
- Good contrast
- No unnecessary clutter

## Branding

- Correct channel
- Correct logo
- Correct typography
- Correct visual identity

## Final Question

Would this still communicate the video's concept at small thumbnail size?
